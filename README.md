This system cannot transmit deletion requests to external companies or third parties, and cannot copy or delete files across external servers. Only files inside your own connected Google Drive can be copied or moved to the trash via explicit instructions.

Options for Handling Data

• Request Data Deletion from Companies (GDPR / CCPA / Privacy Rights): Submit a formal Data Subject Access Request (DSAR) or Right to Erasure request directly through the target company's privacy portal or Data Protection Officer (DPO) email.
• Copy and Delete Your Own Google Drive Files: Specify the exact file name in your Google Drive, and I can create a copy or move the original file to your Drive trash.
